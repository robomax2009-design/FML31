# SOMEL — заставка ФМЛ31

## Структура проекта

- `index.html` — разметка, тексты и карточки QR-кодов.
- `css/style.css` — оформление, цвета, адаптивность и бесконечные анимации.
- `js/main.js` — генерация фоновых частиц и полноэкранный режим.
- `assets/fonts/DwarvenStonecraftCyr.otf` — шрифт из исходного проекта SOMEL.
- `assets/images/qr-site.png` — QR-код сайта ФМЛ31.
- `assets/images/qr-telegram.png` — QR-код Telegram-канала.

## Запуск

Откройте `index.html` в браузере. Для телевизора рекомендуется Chrome/Edge и разрешение 1920×1080. Нажмите `F` или дважды щёлкните по странице для полноэкранного режима.

## Где редактировать

- Тексты и структура: `index.html`
- Цвета, размеры и анимации: `css/style.css`
- Логика анимации частиц и полноэкранного режима: `js/main.js`

QR-коды находятся в `assets/images/`. При замене сохраняйте имена файлов, чтобы ссылки в HTML не менять.
Все пути относительные: переносите всю папку проекта целиком.


## Живая аналитика на телевизоре

В архив добавлена папка `stats/` из проекта аналитики и подключён счётчик уникальных пользователей за сегодня.
Заставка обращается к `/fml31/stats/telemetry.php` каждые 7 секунд. Если количество зафиксированных посещений увеличилось, запускается короткий световой импульс. Сам QR-код не анимируется.

### Установка на сервер

1. Загрузите содержимое папки `stats/` в `/fml31/stats/` на том же PHP-сервере, где находится сайт.
2. Проверьте, что PHP может создавать папки `stats/data/` и `stats/data/sessions/`.
3. Добавьте трекер на все страницы сайта, посещения которых хотите учитывать, перед закрывающим `</body>`:
   ```html
   <script src="/fml31/stats/tracker.js"></script>
   ```
4. Откройте заставку через тот же домен/сервер (например, в `/fml31/television/`). Если она открыта с другого домена, нужно будет настроить API URL и CORS.
5. Проверьте `stats/analysis.html` — это существующая подробная аналитика.

### Как трактуется статистика

- «Уникальные за сегодня» — уникальные `userId` из `localStorage` среди зарегистрированных посещений за текущую дату по часовому поясу PHP-сервера.
- Один и тот же браузер обычно считается одним пользователем; очистка хранилища или другой браузер/устройство создаст другой ID. Это оценка уникальных браузеров, а не гарантированное число реальных людей.
- Пульсатор срабатывает при появлении новых записей о посещениях. Обновление счётчика идёт раз в 7 секунд, поэтому импульс появляется с небольшой задержкой.
- Сейчас трекер записывает загрузку каждой страницы, а не только начало пользовательской сессии.

### Важно про доступ

API отдаёт телевизору только агрегированные значения для текущего дня через `get_live_stats`. В исходной аналитике действие `get_stats` также не требует авторизации. Если подробная аналитика не должна быть публичной, защитите `analysis.html` и действие `get_stats` паролем/авторизацией на сервере.
