Как создать свой VPN?

Можете написать мне в telegram, и я помогу Вам.

  1. Мы будем делать сеть под Happ. Для владельцев IOS можно использовать V2Box.
  2. Зарегистрируйтесь на https://dashboard.render.com/login любым способом
  3. В Dashboard создайте новый Web Service
  4. Выберите Public Git Repository, вставьте ссылку: https://github.com/AssA7778/REN

    Нажмите Connect
  5. В появившейся странице выберите нужный регион
  6. Выберите Free тариф
  7. Если надо задать пароль администратора, в Enviroment Variables будет строка. В поле NAME_OF_VARIABLE пишем ADMIN_PASSWORD. В поле справа от этого пишем придуманный пароль.
  8. Нажмите Deploy New Service
  9. В панели управления будет ссылка на сервис. Копируем её в браузер
  10. Дописываем /dashboard Потом надо будет вписать пароль администратора (или просто admin, если егоо не меняли)
  11. В дешборде открываем вкладку Inbounds, нажимаем + Add
  12. В окне вписываем имя сети и TRAFFIC LIMIT 100 (это лимит сервера, и мы даём ему понять этот лимит)
  13. В появившейся строке справа нажимаем S
  14. Теперь нужно открыть Happ, в меню нажимаем Add URL
  15. В Subscription Name пишем имя сети (любое удобное) и в Subscription URL вставляем ссылку, которая скопировалась в пункте 13.
  16. Пользуемся. По поводу интерфейса, средняя из трёх кнопок - это пинг. Её можно нажимать, чтобы узнать работу сервера (если напротив нужной строки стоит n/a - сервер недоступен.)
