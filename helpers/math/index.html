Основные формулы тригонометрии

Основные тождества

Основное тождество

\(\sin^2 \alpha + \cos^2 \alpha = 1\)

Тангенс и котангенс

\(\tan \alpha = \dfrac{\sin \alpha}{\cos \alpha}\)
\(\cot \alpha = \dfrac{\cos \alpha}{\sin \alpha}\)
\(\tan \alpha \cdot \cot \alpha = 1\)

Производные

\(1 + \tan^2 \alpha = \dfrac{1}{\cos^2 \alpha}\)
\(1 + \cot^2 \alpha = \dfrac{1}{\sin^2 \alpha}\)

Сложение и вычитание углов

Синус

\(\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta\)

Косинус

\(\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta\)

Тангенс

\(\tan(\alpha \pm \beta) = \dfrac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}\)

Кратные углы

Двойной угол

\(\sin 2\alpha = 2 \sin \alpha \cos \alpha\)
\(\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha\)
\(\tan 2\alpha = \dfrac{2\tan \alpha}{1 - \tan^2 \alpha}\)

Тройной угол

\(\sin 3\alpha = 3\sin \alpha - 4\sin^3 \alpha\)
\(\cos 3\alpha = 4\cos^3 \alpha - 3\cos \alpha\)

Сумма → произведение

\(\sin \alpha \pm \sin \beta = 2 \sin \dfrac{\alpha \pm \beta}{2} \cos \dfrac{\alpha \mp \beta}{2}\)
\(\cos \alpha + \cos \beta = 2 \cos \dfrac{\alpha + \beta}{2} \cos \dfrac{\alpha - \beta}{2}\)
\(\cos \alpha - \cos \beta = -2 \sin \dfrac{\alpha + \beta}{2} \sin \dfrac{\alpha - \beta}{2}\)

Произведение → сумма

\(2 \sin \alpha \sin \beta = \cos(\alpha - \beta) - \cos(\alpha + \beta)\)
\(2 \cos \alpha \cos \beta = \cos(\alpha - \beta) + \cos(\alpha + \beta)\)
\(2 \sin \alpha \cos \beta = \sin(\alpha + \beta) + \sin(\alpha - \beta)\)

Понижение степени и подстановка

\(\sin^2 \alpha = \dfrac{1 - \cos 2\alpha}{2}\)
\(\cos^2 \alpha = \dfrac{1 + \cos 2\alpha}{2}\)
\(\sin^3 \alpha = \dfrac{3\sin \alpha - \sin 3\alpha}{4}\)
\(\cos^3 \alpha = \dfrac{3\cos \alpha + \cos 3\alpha}{4}\)

\(t = \tan \dfrac{\alpha}{2}\)

\(\sin \alpha = \dfrac{2t}{1 + t^2}\)
\(\cos \alpha = \dfrac{1 - t^2}{1 + t^2}\)
\(\tan \alpha = \dfrac{2t}{1 - t^2}\)
