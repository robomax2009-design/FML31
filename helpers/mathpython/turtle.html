Простейшие команды. Линейный алгоритм

  • from turtle import * — подключаем все команды черепашки.
  • fd(100) — forward, вперёд на 100 пикселей.
  • bk(50) — backward, назад на 50 пикселей.
  • rt(90) — right, поворот направо на 90°.
  • lt(45) — left, поворот налево на 45°.
  • pu() — penup, поднять перо (не рисует).
  • pd() — pendown, опустить перо (рисует).
  • color("red") — цвет пера.
  • width(3) — толщина линии.
  • speed(5) — скорость рисования (0–10).
  • goto(x, y) — переместиться в точку (x, y).
  • circle(50) — нарисовать окружность радиусом 50.
  • done() — окно не закрывается сразу.

Линейный алгоритм — команды выполняются по порядку, одна за другой.

    Пример: квадрат 
  • from turtle import *

fd(100)
rt(90)
fd(100)
rt(90)
fd(100)
rt(90)
fd(100)

done()

Циклический алгоритм

Цикл повторяет одни и те же команды несколько раз.

  • for i in range(n): — повторить n раз.
  • range(5) — числа 0, 1, 2, 3, 4.
  • range(1, 6) — числа 1, 2, 3, 4, 5.
  • range(0, 10, 2) — 0, 2, 4, 6, 8.

Пример: квадрат через цикл

from turtle import *

for i in range(4):
    fd(100)
    rt(90)

done()

Пример: пятиконечная звезда

from turtle import *

for i in range(5):
    fd(150)
    rt(144)

done()

Пример: n-угольник

from turtle import *

n = 8
for i in range(n):
    fd(80)
    rt(360 / n)

done()

Подпрограммы

Подпрограмма (функция) — это блок команд, у которого есть имя. Её можно вызывать много раз.

  • def имя(): — объявление функции.
  • Тело функции пишется с отступом.
  • Вызов функции: имя().

Пример: функция рисует квадрат

from turtle import *

def square():
    for i in range(4):
        fd(100)
        rt(90)

square()
pu()
goto(150, 0)
pd()
square()

done()

Пример: функция рисует домик

from turtle import *

def house():
    for i in range(4):
        fd(100)
        rt(90)
    rt(45)
    fd(70)
    rt(90)
    fd(70)

house()

done()

Подпрограммы с параметрами

Параметры позволяют передавать в функцию разные значения: длину, угол, цвет, количество повторений.

  • def square(size): — функция с одним параметром.
  • def polygon(size, n): — функция с двумя параметрами.
  • Внутри функции параметры используются как обычные переменные.

Пример: квадраты разного размера

from turtle import *

def square(size):
    for i in range(4):
        fd(size)
        rt(90)

square(50)
pu()
goto(100, 0)
pd()
square(100)
pu()
goto(250, 0)
pd()
square(150)

done()

Пример: правильный многоугольник

from turtle import *

def polygon(size, n):
    for i in range(n):
        fd(size)
        rt(360 / n)

polygon(80, 3)
pu()
goto(150, 0)
pd()
polygon(80, 5)
pu()
goto(320, 0)
pd()
polygon(80, 6)

done()

Пример: разноцветные круги

from turtle import *

def circle_at(color_name, radius, x, y):
    pu()
    goto(x, y)
    pd()
    color(color_name)
    circle(radius)

circle_at("red", 40, 0, 0)
circle_at("green", 60, 120, 0)
circle_at("blue", 80, 260, 0)

done()

Условный оператор

Условный оператор помогает программе выбирать, что делать, в зависимости от условия.

  • if условие: — если условие истинно.
  • else: — иначе.
  • elif условие: — ещё одно условие.
  • Сравнения: >, <, >=, <=, ==, !=.
  • Логические связки: and, or, not.

Пример: черепашка идёт вправо или влево

from turtle import *

direction = input("Куда идти? (вправо/влево): ")

if direction == "вправо":
    fd(100)
else:
    bk(100)

done()

Пример: разный цвет в зависимости от числа

from turtle import *

n = int(input("Введите число: "))

if n > 0:
    color("green")
elif n < 0:
    color("red")
else:
    color("blue")

fd(100)
done()

Пример: рисуем круг, если радиус положительный

from turtle import *

r = int(input("Введите радиус: "))

if r > 0:
    circle(r)
else:
    print("Радиус должен быть больше нуля")

done()

Пример: выбор фигуры

from turtle import *

figure = input("Фигура (квадрат/круг): ")

if figure == "квадрат":
    for i in range(4):
        fd(100)
        rt(90)
else:
    circle(60)

done()
